## 2. Diseño del ETL

### 2.1 Flujo de procesamiento

```
BASE_SIIF_2 (1 974 filas)
  │
  ├── Leer columnas: Nombre_Sector, Vigencia, Valor_VF_Final (Actual)
  ├── Filtrar: Vigencia entre 2025 y 2054, sector no vacío
  └── Pivot: GROUP BY (Nombre_Sector, Vigencia) → SUM(Valor_VF_Final)
             ÷ 1e9 = valor_corriente_mmm
             → vigencias_futuras (193 filas: 29 sectores × años con valor > 0)

TD BITACORA (primeras 75 filas)
  │
  ├── Identificar columnas de años (enteros 2025–2054)
  ├── Extraer fila DEFLACTOR PIB BASE 2026 → deflactor por año
  ├── Extraer fila PIB corrientes → pib_corriente_mmm (÷ 1 000)
  └── Extraer fila PIB constantes 2026 → pib_constante_mmm
             → deflactores_pib (30 filas: años 2025–2054)
```

### 2.2 La deflactación ocurre en la API, no en el ETL

El ETL guarda **pesos corrientes**. La API aplica la fórmula:

```
valor_constante_mmm = valor_corriente_mmm / deflactor
```

Que replica exactamente la fórmula del Excel:

```excel
=(B8 / B$47) / 1 000 000 000
-- B8  = valor corriente SIIF en pesos
-- B$47 = DEFLACTOR PIB BASE 2026
-- /1e9 = convertir pesos → mmm
```

### 2.3 Agrupación en 6 series (API, no ETL)

El endpoint `/api/vigencias_futuras/chart` agrupa los 29 sectores individuales en 6 series para el gráfico. Los primeros 5 sectores se identifican por nombre exacto; todos los demás forman `OTROS SECTORES`:

```python
_VF_SECT_NAMED = [
    "TRANSPORTE",
    "IGUALDAD Y EQUIDAD",
    "HACIENDA",
    "DEFENSA Y POLICÍA",
    "SALUD Y PROTECCIÓN SOCIAL",
]
# OTROS SECTORES = todos los que no están en la lista anterior
```

### 2.4 Recreación de tablas

El ETL ejecuta `DROP TABLE + CREATE TABLE` en cada ejecución para ambas tablas. Esto garantiza que un cambio de esquema en `db/schema.sql` se aplique automáticamente sin necesidad de migraciones manuales.

## 3. Esquema de base de datos

### 3.1 Tabla `vigencias_futuras` (rediseñada)

```sql
CREATE TABLE IF NOT EXISTS vigencias_futuras (
    id                   INTEGER PRIMARY KEY AUTOINCREMENT,
    bitacora_id          INTEGER REFERENCES metadatos_bitacora(id),
    vigencia_exec        INTEGER NOT NULL,   -- año de ejecución
    sector               TEXT    NOT NULL,   -- sector individual (SIIF, sin agrupar)
    valor_corriente_mmm  DECIMAL(14,3),      -- pesos corrientes / 1e9 (sin deflactar)
    UNIQUE(bitacora_id, vigencia_exec, sector)
);
```

**Registros cargados:** 193 filas (29 sectores × años con valor distinto de cero; rango 2025–2054).

> **Diseño anterior (hasta commit 42d30c9):** la tabla guardaba `valor_mmm_ctes` y `pct_pib` pre-calculados, agrupados en 6 series. El nuevo diseño guarda datos crudos por sector individual, delegando la transformación a la capa de API.

### 3.2 Tabla `deflactores_pib` (nueva)

```sql
CREATE TABLE IF NOT EXISTS deflactores_pib (
    id                   INTEGER PRIMARY KEY AUTOINCREMENT,
    bitacora_id          INTEGER REFERENCES metadatos_bitacora(id),
    anio                 INTEGER NOT NULL,
    deflactor            DECIMAL(14,9),        -- DEFLACTOR PIB BASE 2026
    pib_corriente_mmm    DECIMAL(14,3),        -- PIB nominal (miles de millones)
    pib_constante_mmm    DECIMAL(14,3),        -- PIB real pesos constantes 2026 (miles de millones)
    UNIQUE(bitacora_id, anio)
);
```

**Registros cargados:** 30 filas (años 2025–2054).

## 4. Endpoints de API

### 4.1 `/api/vigencias_futuras` — datos crudos

Devuelve los registros individuales por sector en pesos corrientes.

```json
[
  {"vigencia_exec": 2027, "sector": "TRANSPORTE", "valor_corriente_mmm": 10936.0},
  {"vigencia_exec": 2027, "sector": "HACIENDA",   "valor_corriente_mmm": 4560.0},
  ...
]
```

### 4.2 `/api/vigencias_futuras/totales` — totales anuales deflactados

Devuelve el total por año con deflactación aplicada vía JOIN con `deflactores_pib`.

```json
[
  {
    "vigencia_exec": 2027,
    "total_corriente_mmm": 28188.0,
    "deflactor": 1.048,
    "total_constante_mmm": 26895.3,
    "pct_pib": 1.3723
  },
  ...
]
```

### 4.3 `/api/vigencias_futuras/chart` — datos listos para Chart.js

Endpoint principal del gráfico. Retorna 6 series agrupadas en precios constantes 2026 + línea % PIB.
